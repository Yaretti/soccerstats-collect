SoccerSTATS Second-Half Statistics Collector

Python-парсер для збору статистики команд за кількістю голів у другому таймі з SoccerSTATS.

Що збирає парсер

Для кожної команди:

* GP — кількість матчів;
* Avg — середня кількість голів у другому таймі;
* 0.5+ — відсоток матчів із понад 0,5 гола;
* 1.5+ — відсоток матчів із понад 1,5 гола;
* 2.5+ — відсоток матчів із понад 2,5 гола;
* 3.5+ — відсоток матчів із понад 3,5 гола.

Поточний режим

Перший тест налаштований на Англію. Коректність збору необхідно перевірити запуском GitHub Actions.

Як запустити

1. Відкрий репозиторій на GitHub.
2. Перейди у вкладку Actions.
3. Вибери Collect SoccerSTATS second-half stats.
4. Натисни Run workflow.
5. Дочекайся завершення запуску.
6. Завантаж ZIP-архів із розділу Artifacts.

Результати

Основний файл результатів:

output/soccerstats_second_half.csv

Діагностичні файли, якщо вони створені:

debug/

CSV та діагностика завантажуються як артефакти запуску GitHub Actions. Парсер не додає результати автоматично до репозиторію.

Встановлення локально

pip install -r requirements.txt
python src/soccerstats_collect.py

Джерело

https://www.soccerstats.com/halftime.asp

Статистика залежить від доступності сайту та структури його сторінки. Після першого запуску потрібно перевірити, чи парсер знайшов таблицю та зібрав дані.
